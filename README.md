# Real Estate Backend

Backend system developed for the Batanov Homes real estate platform.

The project supports the management of property listings, including creation, editing, publishing, hiding, synchronization, and safe deletion.

## Main Features

- Create and edit property listings
- Publish and hide properties
- Safe deletion workflow
- Synchronization of listing data
- Public property listing management
- API and database integration

## Project Purpose

The backend was created to support a modern real estate platform focused on property rentals and listings in the Varna region, Bulgaria.

I developed and managed the project workflow, backend structure, listing administration, and integrations using AI-assisted development tools.
